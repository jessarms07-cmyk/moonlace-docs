# Moonlace Theme Documentation

Welcome to the official documentation for **Moonlace**, a romantic, editorial Shopify theme designed for boutique and visually driven brands.

Moonlace combines flexible visual storytelling with practical shopping tools, responsive layouts, and conversion-focused storefront features.

Moonlace is especially well suited for:

- Beauty and lifestyle brands
- Handmade goods
- Art and creative products
- Boutique fashion
- Curated specialty collections
- Premium and visually driven stores
