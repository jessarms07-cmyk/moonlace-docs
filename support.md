# Moonlace Support

Need help with Moonlace?

Moonlace support covers setup, built-in theme features, theme settings, confirmed theme bugs, and issues caused by the original Moonlace theme.

Before submitting a support request, review the [Troubleshooting Guide](troubleshooting.md) and [FAQ](faq.md).

## Before Contacting Support

Please check the following first:

1. Confirm the issue occurs while using Moonlace.
2. Confirm you are previewing or editing the correct theme copy.
3. Save recent changes and refresh the storefront.
4. Test the issue in a private or incognito browser window.
5. Note whether the issue began after installing an app or adding custom code.
6. Test the issue in an unmodified Moonlace preview if possible.

Providing this information helps support identify the problem more efficiently.

## Information to Include

When submitting a support request, include:

### Name

Your name or the name we should use when responding.

### Email Address

An email address where you can receive support updates.

### Shopify Store URL

Provide your Shopify store URL.

Example:

`your-store.myshopify.com`

### Moonlace Version

Include the Moonlace version shown in your theme information if known.

### Support Topic

Choose the category that best describes the issue:

- Theme setup
- Header or navigation
- Homepage
- Product page
- Collection page
- Search
- Cart or cart drawer
- Quick Order
- Before & After Slider
- Countdown
- Age Verifier
- Localization or RTL
- Mobile display
- Accessibility
- Theme update
- Possible theme bug
- Other

### Affected Page URL

Include the storefront page where the issue occurs if applicable.

### Device

Examples:

- Desktop computer
- Laptop
- iPhone
- Android phone
- iPad
- Android tablet

### Browser

Examples:

- Chrome
- Safari
- Firefox
- Edge
- Samsung Internet

### Description

Explain:

- What is happening
- What you expected to happen instead

### Steps to Reproduce

For possible bugs, list the exact steps needed to reproduce the issue.

Example:

1. Open a product page.
2. Select a variant.
3. Click Add to Cart.
4. Open the cart drawer.
5. Quantity does not update.

### Screenshots

Attach screenshots when they help demonstrate the issue.

Screenshots are especially useful for:

- Layout problems
- Mobile display issues
- Missing content
- Incorrect spacing
- Error messages
- Theme-editor settings

## Do Not Send Sensitive Information

Never submit:

- Shopify passwords
- Customer passwords
- Credit or debit card information
- Customer payment data
- API keys
- API secrets
- Access tokens
- Authentication codes
- Banking information
- Other sensitive credentials

Moonlace support will not ask you to send passwords or payment credentials through a support form.

## What Standard Moonlace Support Covers

Standard support includes help with:

- Installing and configuring Moonlace
- Understanding theme settings
- Built-in Moonlace sections
- Header and navigation
- Product and collection presentation
- Search presentation
- Cart and cart drawer
- Quick Order
- Before & After Slider
- Countdown
- Age Verifier
- Localization behavior
- RTL behavior
- Responsive and mobile issues
- Accessibility problems caused by Moonlace
- Confirmed Moonlace bugs
- Moonlace update guidance

## What Standard Support Does Not Include

Standard support generally does not include:

- Custom feature development
- Custom section creation
- Store redesign
- Custom Liquid development
- Custom CSS or JavaScript development
- Third-party app repair
- Product entry
- Inventory management
- Marketing services
- SEO campaigns
- Product photography
- Store content creation
- Legal advice
- Tax advice
- Regulatory advice
- Custom integrations

Custom development may require separate professional services.

## Third-Party Apps

Apps can modify parts of the storefront, including:

- Product forms
- Cart behavior
- Search
- Navigation
- Customer accounts
- Product recommendations
- Styling
- JavaScript
- Checkout-related experiences

Moonlace cannot guarantee compatibility with every third-party app.

If a problem begins after installing an app, include the app name in your support request.

## Custom Code

Changes made directly to Moonlace theme files can affect functionality and future updates.

If your store includes custom Liquid, CSS, or JavaScript, include that information in your support request.

Support may first need to determine whether the issue exists in the original Moonlace theme.

## Reporting a Theme Bug

A Moonlace theme bug is an issue that can be reproduced in the original theme without unrelated apps or custom code causing the behavior.

When reporting a possible bug, include:

- Moonlace version
- Store URL
- Affected page
- Steps to reproduce
- Expected behavior
- Actual behavior
- Device
- Browser
- Screenshots or screen recordings where useful

## Accessibility Issues

Accessibility reports involving Moonlace should include:

- Affected page
- Control or content involved
- Browser
- Device
- Assistive technology if applicable
- Steps to reproduce

Accessibility issues caused by Moonlace will be treated as theme-product issues rather than ordinary customization requests.

## Response Information

Support requests containing complete reproduction details can usually be investigated more efficiently.

A message such as:

`The theme is broken`

contains remarkably little forensic evidence.

A stronger request would include:

- Page URL
- Exact steps
- Screenshot
- Browser
- Device
- Recent changes
