# Getting Started with Moonlace

Welcome to Moonlace.

Moonlace is a romantic, editorial Shopify theme designed for boutique and visually driven brands. It combines flexible visual storytelling with practical shopping tools, responsive layouts, and conversion-focused storefront features.

## Before You Begin

Before customizing Moonlace, it helps to have the following ready:

- Your brand logo
- Brand colors
- Product photography
- Product titles and descriptions
- Collections
- Navigation menus
- Store policies
- Contact information
- Social media links, if used

Using real store content during setup will give you a much more accurate preview than placeholder content.

## Install Moonlace

After Moonlace is added to your Shopify store:

1. Open your Shopify admin.
2. Go to **Online Store > Themes**.
3. Find Moonlace in your theme library.
4. Click **Customize** to open the theme editor.

We recommend customizing and testing Moonlace before publishing it to your live storefront.

## Using the Shopify Theme Editor

Moonlace uses Shopify's visual theme editor.

From the theme editor, you can:

- Add sections
- Remove sections
- Reorder sections
- Add and remove blocks
- Edit text and images
- Adjust colors and typography
- Configure product and collection presentation
- Preview desktop and mobile layouts

Changes can be previewed before they are published.

## Recommended Setup Order

For the smoothest setup process, we recommend working in this order:

1. Configure your logo and branding.
2. Set colors and typography.
3. Configure the header and navigation.
4. Set up homepage sections.
5. Review product pages.
6. Review collection pages.
7. Configure cart and shopping features.
8. Add optional Moonlace specialty features.
9. Review the footer.
10. Test the storefront on desktop and mobile.

## Preview Before Publishing

Before making Moonlace live, test:

- Main navigation
- Mobile navigation
- Search
- Products
- Product variants
- Collections
- Add to Cart
- Cart drawer
- Quantity updates
- Quick Order, if enabled
- Specialty sections
- Footer links
- Contact information
- Mobile presentation
