# Moonlace Theme Setup

This guide covers the main setup areas you should configure before building out individual pages and specialty features.

## Open the Theme Editor

1. In Shopify admin, go to **Online Store > Themes**.
2. Find Moonlace.
3. Click **Customize**.

The theme editor lets you preview and configure Moonlace without publishing changes immediately.

## Global Theme Settings

Open **Theme settings** to configure site-wide styling and behavior.

Depending on the Moonlace version, settings may include:

- Colors
- Typography
- Buttons
- Layout
- Product presentation
- Cart behavior
- Visual effects
- Localization-related presentation
- Other global storefront settings

## Logo

To configure your logo:

1. Open the **Header** section.
2. Select your logo image.
3. Adjust available logo sizing settings.
4. Preview the result on desktop and mobile.

For best results:

- Use a high-quality image.
- Avoid excessive empty space around the logo.
- Make sure it remains readable against the header background.
- Preview narrow mobile widths.

If no logo is selected, your store name may be shown instead.

## Favicon

A favicon is the small icon shown in browser tabs and bookmarks.

To configure it:

1. Open **Theme settings**.
2. Locate the favicon setting.
3. Upload a square image.
4. Save your changes.

A simple, recognizable version of your logo usually works best.

## Colors

Use Moonlace color settings to match the storefront to your brand.

When choosing colors:

- Maintain readable contrast between text and backgrounds.
- Test buttons against every background where they appear.
- Avoid using very low-contrast text.
- Check both desktop and mobile presentation.

## Typography

Moonlace typography settings allow you to configure the visual tone of your storefront.

When choosing fonts:

- Prioritize readability.
- Avoid using too many different font styles.
- Test long headings on mobile.
- Make sure buttons and product information remain easy to read.

## Header

The header contains your primary navigation and key storefront controls.

Typical header configuration includes:

- Logo
- Main menu
- Search
- Cart access
- Localization controls, if enabled
- Mobile navigation behavior

After changing header settings, test both desktop and mobile navigation.

## Main Navigation

Shopify menus are managed outside the theme editor.

To configure your main menu:

1. Open Shopify admin.
2. Go to your store's navigation or menu settings.
3. Create or edit the menu you want to use.
4. Return to the Moonlace theme editor.
5. Open the **Header** section.
6. Select the appropriate menu.
7. Save.

Test:

- Top-level links
- Nested links
- Long labels
- Mobile menu opening and closing
- Navigation back to the homepage

## Homepage Sections

Moonlace uses Shopify sections to build the homepage.

Sections can generally be:

- Added
- Removed
- Reordered
- Configured independently

To add a section:

1. Open the homepage in the theme editor.
2. Click **Add section**.
3. Choose the section you want.
4. Configure its settings.
5. Save.

Use only the sections that support your store's content and goals. More sections do not automatically create a better storefront. Sometimes they simply create scrolling as a lifestyle.

## Recommended Homepage Structure

A strong Moonlace homepage may include:

1. Brand introduction or hero section
2. Featured collection or products
3. Editorial or storytelling content
4. Promotional messaging
5. Specialty section, if relevant
6. Additional product discovery
7. Supporting trust or information content
8. Footer

The exact structure should reflect your store rather than the demo store exactly.

## Images

Moonlace is designed for strong visual presentation.

For best results:

- Use high-quality product and lifestyle images.
- Avoid unnecessarily large file sizes.
- Keep important subjects away from image edges.
- Preview image cropping on mobile.
- Use consistent visual styling when possible.

## Buttons and Calls to Action

Keep button text clear and specific.

Examples:

- Shop the Collection
- View Product
- Explore New Arrivals
- Learn More
- Add to Cart

Avoid vague button labels when a clearer action is available.

## Footer

Use the footer for important secondary navigation and store information.

Common footer links include:

- Contact
- FAQ
- Shipping
- Returns
- Privacy policy
- Terms
- Product care
- Social media
- Newsletter signup

## Previewing Changes

Before publishing major theme changes:

1. Preview desktop.
2. Preview mobile.
3. Test navigation.
4. Open product pages.
5. Open collection pages.
6. Test cart behavior.
7. Review the footer.
8. Check specialty features you enabled.

## Publishing Moonlace

When setup and testing are complete:

1. Return to **Online Store > Themes**.
2. Find Moonlace.
3. Use Shopify's publish option to make it your active storefront theme.

Do not publish until you have tested the storefront with real content.
